# Recommended Tools

Use online [draw.io](https://app.diagrams.net/)
or download and install the [desktop version](https://github.com/jgraph/drawio-desktop). Save the *.drawio* files created by drawio here and export diagrams to svg format and save the *.svg* files here as well.

**Important:** *.drawio* and *.svg* files are text files. **DO NOT** post binary files in Bitbucket!!!
